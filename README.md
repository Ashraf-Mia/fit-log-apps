# FitLog - Workout Library

FitLog is a workout library web application where users can explore different exercises, view workout details, add exercises to today's plan, and save workouts for later.

## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
- DaisyUI
- React Icons

## Key Features

- See all workouts from the FitLog API.
- See workout details.
- Add workouts to Today's Plan.
- Save workouts for later.
- See Today's Plan and Saved workouts.
- See total exercises, time, and calories.
- Sort workouts by Duration, Calories, and Rating.
- Mark workouts as done.
- Remove workouts from the plan.
- Works well on mobile, tablet, and desktop.
- Shows loading spinner and toast messages.
- Shows a custom 404 page for wrong URLs.

## Responsive Design

FitLog is fully responsive and works on:

- Mobile
- Tablet
- Desktop

## API
